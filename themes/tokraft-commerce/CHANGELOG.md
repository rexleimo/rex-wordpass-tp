# Changelog

## 1.2.0 - 2026-07-27

- Replaced the broken `/search/` link with an accessible search dialog and native WordPress results page.
- Added responsive mixed results for products, services, case studies, pages, and editorial content.
- Enabled WooCommerce account registration, checkout account creation, saved billing and shipping addresses, and login reminders.
- Added account navigation, login, registration, order, and address-management styling without introducing a membership plugin.

## 1.1.0 - 2026-07-27

- Added self-hosted GSAP and ScrollTrigger assets for the commerce home page.
- Added orchestrated hero, section reveal, media parallax, metric counter, and magnetic button motion.
- Added reduced-motion handling and kept all animation enhancements isolated from commerce interactions.
