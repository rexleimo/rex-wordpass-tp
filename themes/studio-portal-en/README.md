# Studio Portal International

Studio Portal International is an English WordPress newsroom theme. Its home page is assembled from normal WordPress content, so editors can publish and reorganize the site without editing PHP templates.

## Editorial workflow

- Publish or update a normal Post while the theme is active to add it to **Latest** automatically.
- Add a **Featured image** to replace the built-in SVG artwork wherever that article appears on the home page.
- Use **Categories** as Topic Desks. Each populated category can appear in Topics and has its own archive page.
- Assign a **Column** in the post editor to add the story to a recurring column and its archive.
- Use the **Newsroom placement** box in the post editor to curate the Lead story, Trending / Most Read, Daily Briefing, and Editor's Picks.
- A WordPress sticky post becomes the Lead when no article is explicitly assigned as the Lead story.

Curated modules fall back to the newest published stories when they do not have enough manually selected articles, so the home page remains complete during day-to-day publishing.

The theme keeps an internal content marker on these posts. This prevents posts created for another theme in a shared WordPress installation from leaking into the international newsroom; it does not create a custom post type or change how editors manage the articles.

## Newsroom settings

Go to **Appearance > Newsroom setup** to edit:

- Issue and edition labels
- Newsletter email address and subscriber label
- Briefing title and one-signal-per-line summary

The setup screen also links directly to the post, category, and column management screens.

## Demo content

The theme creates a small set of editable English demonstration posts and column terms when first activated. They are standard WordPress records: editors can modify, unpublish, or replace them normally.
