# Changelog

## 0.3.0 - 2026-07-27

- Made every home-page news module query standard WordPress posts instead of fixed template slots.
- Added native Newsroom placement controls for the lead, Most Read, Briefing, and Editor's Picks.
- Added a public Columns taxonomy and connected Categories to the Topic Desks module.
- Added Appearance > Newsroom setup for issue, edition, newsletter, and Briefing copy.
- Added featured-image support across the home page while keeping the built-in artwork as a fallback.
- Added dynamic category and column archive headers for normal editorial browsing.
- Scoped newsroom queries and archives to international-theme content to prevent cross-theme category leakage.

## 0.2.0 - 2026-07-27

- Reframed the home page as a high-density international newsroom rather than a studio landing page.
- Added Latest, Most Read, Columns, Topic Desks, Briefing, Editor's Picks, and newsletter sections.
- Added eight editable English demo stories and recurring column tags.
- Fixed WordPress menu list items not filling the desktop header height.
- Added sticky-header offsets for the logged-in WordPress admin bar.
- Updated the default navigation and editorial metadata for the publication format.

## 0.1.0 - 2026-07-27

- Initial international studio theme based on the WP2 Pencil design.
- Added responsive home, work, case, services, studio, process, journal, contact, and article views.
- Added local project artwork, accessible mobile navigation, project filtering, contact handling, and GSAP motion.
